# Titanic EDA — Exploratory Data Analysis

## Overview
An exploratory data analysis of the Titanic passenger dataset to understand 
what factors influenced survival during the disaster.

## Dataset
- Source: Seaborn built-in Titanic dataset
- 891 passengers, 10 features after cleaning

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib

## Key Findings
1. Overall survival rate was 38.4%
2. Females were 3.4x more likely to survive than males
3. First class passengers had a 62.9% survival rate vs 24.2% for third class
4. Children under 10 had higher survival rates than any other age group
5. Passengers travelling with 1-3 family members had better survival chances
